# Stock Glance 台股觀測

用 Google Apps Script 部署的手機版看盤網頁。打開一個網址就能看到：

- **總覽**：七個指標組成的「反彈訊號儀表」，判斷規則全部公開；另有加權指數、台積電、費半、那指、標普 500、台積電 ADR、VIX、美元兌台幣的指標卡（附 60 日走勢線）
- **持股**：在網頁上直接「新增交易」，用代號或名稱搜尋全部上市櫃股票與 ETF，填股數和成交價即可，手續費和交易稅自動計算。可以分批用不同價格買進、零股、部分賣出。持股以平均成本法計算即時市值、未實現損益、已實現損益、今日損益、扣除費稅後的賣出淨損益，以及損益兩平價。點進個股可以看 1 個月到 5 年的走勢、MA5／MA20／MA60、成本線、每一筆交易、近 12 個月配息與估算殖利率
  - **配息入帳與含息損益**：「新增交易 › 配息」記錄每次入帳的現金配息（自動預估二代健保補充保費，可改成實際金額）。持股頁顯示「累計領息」與「含息損益」，高股息 ETF 不會再因為除息而看起來虧很多。程式會比對 Yahoo 的除息資料，列出「可能還沒記錄的配息」，一鍵帶入
  - **資產類別與核心／衛星**：依名稱與備註自動把持股分成台股／海外股票／債券，以及市值型、高股息、主動式等風格，並標成核心或衛星（個股頁可以手動切換）
  - **投資規則提醒**：衛星合計或單一衛星超過「設定」分頁的上限、或全部持股都在同一個類別時，持股頁會提醒
- **籌碼**：三大法人買賣超與融資餘額，每個交易日晚上自動更新，附官方資料連結
- **觀察**：市場觀察與持股診斷筆記，內容直接在 Sheet 的「觀察筆記」分頁維護

盤中每 60 秒自動更新報價。漲跌顏色依台股慣例：紅漲綠跌。

## 架構

```
GitHub Pages（docs/，網頁）
   │  fetch ?api=…&key=…
   ▼
Apps Script（src/，JSON API）
   ├─ 證交所 MIS 即時報價  （盤中台股與加權指數）
   ├─ Yahoo Finance 日線   （美股、VIX、匯率、歷史走勢、配息）
   ├─ 證交所盤後資料       （三大法人 BFI82U、融資 MI_MARGN、個股日成交備援）
   └─ Google Sheet         （持股、籌碼紀錄、觀察筆記、設定）
```

GitHub 上只有程式碼，沒有任何持股資料。API 金鑰存在 Apps Script 的指令碼屬性，以及你自己瀏覽器的 localStorage。

| 檔案 | 用途 |
| --- | --- |
| `docs/index.html` `styles.css` `app.js` | 網頁（GitHub Pages）。不依賴任何外部 JS 套件，圖表為自繪 SVG |
| `docs/glossary.js` | 名詞小辭典：網頁上每個「?」的白話說明與延伸閱讀連結 |
| `src/Code.gs` | `doGet` JSON API、損益計算 |
| `src/Fetchers.gs` | 所有對外抓資料的程式與快取 |
| `src/Signals.gs` | 反彈訊號的判斷規則 |
| `src/Ledger.gs` | 交易帳本（平均成本法）、新增／刪除交易、上市櫃代號表 |
| `src/Setup.gs` | 初始化、API 金鑰、每日排程、籌碼回補 |
| `src/Config.gs` | Sheet ID、指標清單、資料連結 |
| `tests/harness.js` | 用假服務與合成資料在本機測試後端並產生預覽頁 |

## 資料 Sheet

預設使用 [Stock Glance 持股與資料](https://docs.google.com/spreadsheets/d/12_HJ7xI7NCCBNMayjWJnVbUVbucCvt5r9apdOOCgT1w/edit)。分頁：

- **交易紀錄**：`日期｜代號｜名稱｜動作｜股數｜成交價｜手續費｜交易稅｜淨收付｜類型｜市場｜備註｜ID`。建議從網頁的「新增交易」寫入；要手動加也可以，但代號欄必須是純文字格式（否則 `0050` 會變成 `50`）。日期空白代表期初庫存。
  - 「動作」是 **配息** 的列：股數＝領息股數、成交價＝每股配息、手續費＝扣除額（補充保費＋匯費）、淨收付＝實際入帳金額。配息不影響股數與平均成本。
- **持股**：由交易紀錄自動產生，每次新增或刪除交易後會重建，只有「備註」與「角色」欄可以自己編輯（會保留）。「角色」填 `核心` 或 `衛星`，空白代表自動判斷；備註裡寫「債券」「海外」「市值型」「高股息」等字，可以覆蓋自動分類。
- **籌碼**：由程式自動寫入，不用手動編輯。
- **觀察筆記**：`日期｜分類｜標題｜內容`，新增一列就會出現在網頁上。
- **設定**：手續費折扣、最低手續費、自動刷新秒數，以及兩個訊號門檻。另外可以新增這幾列（沒有就用預設值）：
  - `衛星比重上限(%)`（預設 20）、`單一衛星上限(%)`（預設 10）：持股頁的規則提醒，填 0 代表不提醒
  - `配息提醒起算日`（例如 `2026-11-01`）：更早的除息不列入「可能還沒記錄的配息」。沒填時，期初庫存只看近 120 天

要改用別的 Sheet，可以修改 `Config.gs` 的 `SHEET_ID`，或在 Apps Script「專案設定 › 指令碼屬性」新增 `SHEET_ID`。

## 部署

### 1. Apps Script（API）

1. 在 <https://script.google.com> 建立專案，把 `src/` 的 7 個檔案貼進去（`appsscript.json` 要先在「專案設定」勾選顯示資訊清單檔案）。
2. 執行 `setup` 並授權：建立 API 金鑰與分頁；若交易紀錄是空的，會把持股分頁轉成期初庫存；建立每日 22:00 籌碼排程，並回補 25 個交易日的籌碼。
3. 執行 `showApiKey`，從「執行記錄」複製金鑰。
4. 「部署 › 新增部署作業 › 網頁應用程式」：執行身分選**我**、存取權選**任何人**。之後改程式時，用「管理部署作業 › 編輯 › 版本：新版本」，網址就不會變。

金鑰外流時執行 `rotateApiKey`，舊金鑰會立刻失效。

### 2. GitHub Pages（網頁）

repo 的 **Settings › Pages › Build and deployment** 設定：Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/docs`，按 Save。約 1 分鐘後網址是 `https://torusmith.github.io/stock-glance/`。

第一次打開時，網頁會要求輸入 API 網址與金鑰，只需要設定一次（每台裝置各設定一次）。手機可以用「加入主畫面」。

### 3.（選用）GitHub Actions 自動更新 Apps Script

在 **Settings › Secrets and variables › Actions** 新增：

- `CLASPRC_JSON`：本機 `npm i -g @google/clasp@2.4.2 && clasp login` 後，`~/.clasprc.json` 的完整內容
- `SCRIPT_ID`：Apps Script 專案 ID（專案設定頁）
- `DEPLOYMENT_ID`：網頁部署的 ID（管理部署作業頁）

設定好之後，`src/` 的變更推到 `main` 就會自動同步到 Apps Script，並更新同一個部署。網頁本身（`docs/`）則由 GitHub Pages 自動發布。

## 反彈訊號規則

| 指標 | 偏多 | 偏空 |
| --- | --- | --- |
| 費半止跌 | 站上 5 日線且當日收紅 | 創 20 日新低，或跌破 5 日線且跌逾 2% |
| 恐慌退燒（VIX） | 低於 20，或從 30 以上的高點回落 20% | 30 以上且接近 10 日高點 |
| 美股趨勢（標普 500） | 站上 20 日線 | 在 20 日線下且 20 日線下彎 |
| 台幣動向 | 5 日升值逾 0.3% | 5 日貶值逾 0.3% |
| 加權止跌 | 站上 5 日線且 5 日線翻揚 | 同時跌破 5 日線與季線 |
| 外資回補 | 近 3 日合計買超 | 近 3 日合計賣超超過門檻（預設 300 億） |
| 融資清洗 | 5 日減少逾 3% | 5 日增加逾門檻（預設 3%） |

規則刻意保持簡單，可以在 `Signals.gs` 自行調整。這些訊號只是整理公開資料的輔助工具，不構成投資建議。

## 已知限制

- 證交所 MIS 報價延遲約數秒，Yahoo 資料延遲約 15～20 分鐘。Yahoo 用的是非官方介面，改版時可能需要調整 `Fetchers.gs`。
- 證交所會限制查詢頻率，回補籌碼時每次請求之間會間隔 2 秒。
- Apps Script API 第一次呼叫需要 2～5 秒（要抓十幾個資料源）。之後有快取，會快很多。
- 台指期夜盤、期貨未平倉沒有穩定的公開介面，目前只提供期交所連結。
